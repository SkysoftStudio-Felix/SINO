# English-language release notes

The documentation, folder names, and launcher names in this archive are in English.

The system ISO, preinstalled virtual disk, native applications, and compiled packages are the same bilingual SINO 0.10 / SysBASIC 0.3.0 build as the Chinese archive. Choose English in SINO > System Settings. The included screenshots were captured with the Chinese locale.

Chinese interface strings, the Pinyin dictionary, and Chinese text in the sample project remain part of the bilingual system and are preserved in the source/runtime. Third-party license and attribution files are also retained as supplied. No licensed text or data was rewritten.
