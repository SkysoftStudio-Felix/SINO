# SINO Code and Third-Party Sources

The bootloader, SINO32 kernel, hardware drivers, memory manager, FAT12 reader, VFS, persistent data volume, SINO SH, desktop, and built-in applications are C/x86 assembly code generated, written, and modified for this project during this conversation. No FreeDOS, Linux, macOS, iPadOS, or Codex application/kernel source was imported.

Project code is licensed under the repository's MIT license. This describes the implementation's provenance; it does not claim that standard algorithms, protocols, or common patterns are original inventions. The current SINO kernel is not a traditional DOS kernel, SINO SH is not Bash, and neither has binary compatibility with those systems.

| Area | Files |
| --- | --- |
| BIOS boot and protected-mode entry | src32/boot.asm, loader.asm, entry.asm |
| Interrupts, paging, memory, PS/2, absolute mouse, FAT12 | src32/kernel.c |
| Files, paths, copy, and move | src32/vfs.c |
| ATA PIO, dual snapshots, CRC32, and recovery | src32/storage.c |
| Window-surface cache, clipping, fonts, pointer, partial display updates | src32/graphics.c |
| Desktop, window manager, Files, TextEdit, Calculator, Paint, Clock, Terminal views | src32/gui.c |
| Command interpreter, scripts, pipes, editing, and scrolling terminal | src32/shell.c, console.c |

| Real QEMU input, display-memory, and disk validation | tools/vm-test.js, test-desktop.js, test-volume.js |

The visual design follows the user-requested Mac OS 8.5 Platinum style with smoother text and simplified controls. Icons, desktop patterns, window drawing, and pointer outlines are generated by project code; Apple artwork was not copied.

## Public interfaces and references

- [Intel Software Developer's Manual](https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html): protected mode, interrupts, paging, and exceptions.
- [QEMU vmmouse device source](https://github.com/qemu/qemu/blob/master/hw/i386/vmmouse.c): reference for the VMware-compatible absolute-pointer protocol. tools/vmmouse-reference.c and vmport-reference.h are upstream reference files retained under their original licenses; they are not compiled or linked into SINO. The kernel implements port access according to the public device protocol.
- [QEMU system-monitor protocol reference](https://www.qemu.org/docs/master/interop/qemu-qmp-ref.html): used for host-side test input and display screenshots.

The project's MIT license does not replace these component licenses. The VM's about, credits, and /boot/sources.txt also describe provenance.

## Chinese text and Pinyin (version 0.8)

- Chinese bitmap glyphs use a subset of basic Han characters, punctuation, and full-width characters from [GNU Unifont 16.0.04](https://unifoundry.com/pub/unifont/unifont-16.0.04/), under SIL OFL 1.1. The original hex.gz, OFL, COPYING (including attribution), README, and SHA-256 are under tools/fonts/unifont. CJK_OFL.TXT is included on the boot image.
- Character pronunciations use [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data), MIT, pinned to commit 9193766130af24d2ac54230be979b2e98ac66223. Original data, license, and hashes are under tools/pinyin; PINYIN.TXT is on the boot image.
- UTF-8 decoding, glyph lookup, candidate panel, single-character input, and a handwritten list of common words are project code. No other operating system's input-method implementation was imported. Sentence prediction is not provided.
- File context menus, drag-and-drop, desktop icon positions, current-folder navigation, and wide-character terminal cells are implemented in this project.

## Hard-disk installation and system settings (version 0.9)

The disk driver, MBR boot, EDD partition boot, partition planning, graphical setup wizard, sector-by-sector verification, system settings, display scaling, contrast mapping, and Chinese/English string table are project-written code. Windows was used only as an interaction reference for the setup wizard; its installer, icons, and branding assets were not imported.

The disk layout follows the [Legacy MBR records in the UEFI specification](https://uefi.org/specs/UEFI/2.10/05_GUID_Partition_Table_Format.html). Boot uses BIOS EDD extensions. Runtime video modes use the public DISPI register interface of QEMU standard VGA; this interface does not depend on the Bochs emulator.

The installed system contains FAT12 boot resources and SINO's own dual-snapshot data partition. It remains a BIOS/MBR prototype: GPT, UEFI, process isolation, and general application-binary compatibility are unsupported. Data snapshot and VFS capacity limits remain. Testing includes booting from the hard disk after removing the ISO and checking file persistence across reboot.

## Modules added in version 0.10

This release adds src32/process.c, object.c, api.h, and net.c for Ring 3, threads/preemption, handles/system calls, and a loopback protocol stack. user/ contains the independent installer, common runtime, file/editor/task applications, and SysBASIC. These C/assembly additions were written for this project; no Windows, VB6, Linux, or FreeDOS implementation was imported. Algorithms and interfaces refer to Intel SDM and RFC 791/792/768/9293/1035.

Older built-in applications remain in kernel mode; only newer native programs have process isolation. SysBASIC and networking have explicit unfinished items in docs/REPORT.md, network.md, and ide.md. Fonts, Pinyin, firmware, QEMU, and build tools retain the third-party terms described above.

## SysBASIC 0.2 and 0.3

SysBASIC 0.2 (2026-10-24) added the classic docked workbench, output-mode chooser, embedded native resources, software-library integration, and regression tests. No Microsoft VB6 source, binaries, icons, or fonts were imported. BASIC remains an interpreter subset; the standalone output embeds its runtime and project instead of compiling BASIC into new x86 instructions.

SysBASIC 0.3 (2026-10-24) added the keyboard decoder, independent modifier states, eight-handle designer, rectangle drawing, cancellation, First tutorial, and three-folder export. The public release does not bundle QEMU or its firmware/libraries; users install Windows QEMU separately. NASM remains included as a build tool under its BSD license. Font and Pinyin notices remain with the source and runtime resources.
